# Método creativo OMEGA (tiempo real)

## Principio
No esperar “inspiración”: ejecutar un bucle corto con evidencia.

## Bucle (≤ 1 ciclo por pedido)
1. **INTENTS** — 1 frase del mando (qué crear, para quién, formato).
2. **SEEDS** — 3 semillas conflictivas (estilo A / B / C).
3. **VARIANTES** — construir 3 candidatos mínimos (no perfectos).
4. **JUEZ DUAL** — utilidad × asombro; descartar 2; mutar 1.
5. **PUBLICAR** — GitHub release/push o archivo en artifacts con SHA.
6. **FÉNIX** — log: qué falló, qué se aprendió, guardia.

## Conectores MCP reales (esta cuenta)
| Conector | Uso creativo |
|----------|----------------|
| **GitHub** | push, release, repo = entrega en caliente |
| **Automations** | mutar/crear en horario o evento |
| **Notion** | memoria de proyecto / skills MCP |
| **Gmail** | mandar build al mando |
| **Canva** | assets visuales |
| **Voice** | narrar mutaciones |

## Anti-humo
- No afirmar “MCP daemon en el teléfono” si solo hay bridge de contrato.
- Capacidad ≠ Verificación: cada tool debe dejar evidencia (hash, URL, log).
